# Rick roll media

The lab terminal's two `.VID` files (`WATCH_IF_YOU_ARE_ROLLING` and
`WATCH_IF_YOU_ARE_NOT_ROLLING`) play whatever you put here. It isn't shipped
with the game, and `.gitignore` keeps it out of the repo.

- `rickroll.gif` (or `.png` / `.jpg` / `.webp`): the picture. An animated GIF plays at its own frame rate.
- `rickroll.ogg` (or `.mp3` / `.wav`): the song. Playback ends when the song does.

Either one on its own works. A picture with no song runs for 20 seconds. With
neither, the terminal says TAPE MISSING.
